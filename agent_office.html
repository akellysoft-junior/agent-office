세션 재생 · Claude Code 로그

세션 로그(.jsonl)를 여기에 끌어다 놓으세요

실시간으로 보려면: agent_office_server.py를 이 HTML과 같은 폴더에 두고 python3 agent_office_server.py 실행 → 자동으로 열리는 페이지가 라이브 모드로 켜져요. 세션마다 사무실 한 채에 대장 고양이가 입주하고, 서브에이전트는 새끼냥으로 출근해 책상이 하나씩 늘어나요. 할 일이 없으면 휴게공간에서 쉬고, 명령을 기다릴 땐 문 앞에서 기다려요. 사무실을 누르면 확대돼요.
재생용 로그 위치: ~/.claude/projects/<프로젝트>/<세션ID>.jsonl — Read·Grep→도트, Edit·Bash→비트, 서브에이전트→픽셀, 에러→체크, 요청·응답→루미.

실제 에이전트 연동하기

지금은 시뮬레이션이지만, 콘솔이나 외부 스크립트에서 아래 API로 실제 이벤트를 밀어 넣을 수 있어요. 이 HTML을 받아 로컬에서 띄우면 WebSocket과도 바로 연결됩니다.

// 새 작업 투입
office.addTask("푸시 딥링크 버그 수정");

// 에이전트 상태 직접 지정
office.setStatus("coder1", "빌드 돌리는 중…");

// 로그 한 줄 추가
office.log("CI 파이프라인 통과", "good");

// JSONL 문자열로 세션 재생 시작/종료
office.loadLog(jsonlText, "my-session.jsonl");
office.stopReplay();
